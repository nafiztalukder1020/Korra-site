KORRA WEBSITE - VERCEL-E LIVE KORAR NIYOM
1) Char-ta zip (1-main, 2-posters, 3-videos, 4-videos) ek-i folder-e unzip korun (korra-site). Sob mile ei folder hobe:
   index.html, proposal.html, vercel.json, logo/, logos/, posters/, reels/, hero/, team/, img/
2) Computer-e Node.js install korun (nodejs.org, LTS).
3) Terminal/CMD khule korra-site folder-e jan, likhun:   npx vercel
   - Vercel account-e login korte bolbe (Google/GitHub/email).
   - Sob proshno-te Enter chapun (default).
4) Preview link pabe. Thik thakle likhun:   npx vercel --prod
   -> https://<nam>.vercel.app live hoye jabe.
Proposal Builder: https://<nam>.vercel.app/proposal
